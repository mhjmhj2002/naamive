# Runtime Python — DEPRECATED

Este runtime está deprecated durante a migração para a plataforma Node/Web.
Permanece temporariamente como referência de regras, contratos, testes e
comportamento de paridade. Não recebe novas funcionalidades de produto.

O runtime Node é o destino operacional. Após o corte controlado definido em
`naamive/orchestration/demand-intake/node-web-orchestration-platform/`, este
diretório e seus testes legados serão removidos de forma explícita e rastreável.
