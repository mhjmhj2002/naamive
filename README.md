# NAAMIVE

> Transforming Business Needs into Delivered Software.

NAAMIVE é uma plataforma de engenharia de software orientada a transformar necessidades de negócio em produtos de software entregues.

A plataforma global fica em `naamive/`; os produtos originados por necessidades aprovadas ficam, de forma independente, em `projects/`.
